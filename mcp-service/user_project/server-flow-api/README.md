# server-flow-api

Generated by Server Flow - Complete Backend API

## Quick Start

```bash
npm install
cp .env.example .env
npm run dev
```

## API Endpoints

| Method | Endpoint | Description | Auth |
|--------|----------|-------------|------|
| POST | `/api/user/post` | make the user data post like name and age . | No |
| GET | `/api/user/get` | make the route to get the user data . | No |
